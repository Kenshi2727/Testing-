### User Stories

1. **User Registration**

   > As a new user, I want to create an account using my name, email, and password so that I can access the blog application.

2. **User Login**

   > As a registered user, I want to log in using my credentials so that I can access my account and personalized features.

3. **Create Blog Post**

   > As an authenticated user, I want to create and publish a blog post with a title, content, and category so that I can share my thoughts with others.

4. **Edit Blog Post**

   > As a blog author, I want to edit my published posts so that I can correct mistakes or update the content.

5. **Delete Blog Post**

   > As a blog author, I want to delete my own posts so that I can remove content that I no longer want to publish.

6. **View Blog Posts**

   > As a user, I want to view published blog posts so that I can read and discover content from other authors.

7. **Search Blog Posts**

   > As a user, I want to search for blog posts using keywords so that I can quickly find content relevant to my interests.

8. **Comment on Posts**

   > As a logged-in user, I want to comment on blog posts so that I can share my opinions and interact with other users.

9. **Like Blog Posts**

   > As a logged-in user, I want to like blog posts so that I can show appreciation for content I find useful or interesting.

10. **Manage User Profile**

> As a registered user, I want to view and update my profile information so that my account details remain accurate.
